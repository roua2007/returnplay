# ReturnPlay — مولّد برامج التأهيل

أداة ويب تعمل **بدون إنترنت وبدون خادم** تساعد المدرب لما يكون عنده لاعب مصاب (أو تقرير طبي فيه مشكلة عضلات/مفاصل) على توليد **مسودة برنامج تدريبي تأهيلي** مدعومة برسوم توضيحية وفيديوهات شرح لكل تمرين، وتتابع اللاعب من أول إصابة لحد الرجوع للملاعب.

## التشغيل

افتح ملف `index.html` بالمتصفح مباشرة (دبل كليك) — أو استخدمها أونلاين من الاستضافة. كل البيانات تُحفظ محليًا في متصفح الجهاز (localStorage) ولا شيء يُرفع لأي مكان.

> أفضل تجربة على كروم/إيدج. على نفس الجهاز افتحها بنفس المتصفح دايمًا حتى تجد بياناتك.

## تثبيتها كتطبيق (PWA)

من صفحة النسخ الاحتياطي اضغط «📲 تثبيت على هذا الجهاز» (أو من قائمة المتصفح: تثبيت التطبيق / إضافة إلى الشاشة الرئيسية). هتنزل أيقونة على الشاشة وتفتح من غير متصفح وتشتغل أوفلاين بالكامل.

## طريقة الاستخدام (٣ خطوات بسيطة)

اضغط «🚑 عندي لاعب مصاب — ابدأ هنا» وامشي مع المعالج:

1. **فين المشكلة؟** — اختار من جسم اللاعب كل المناطق اللي بتوجعه (مش منطقة واحدة — الحد ٤)، كل منطقة عليها علامة عضلة 💪 أو مفصل 🦴.
2. **احكي عن الإصابة** — اكتبها بالعامية (مثال: «من أسبوعين عندي شد في القطنية يمين بيجيب ألم لما أركض») وارفع التقرير الطبي لو معاك (صورة أو PDF). المحلل العربي المدمج يفهم الوصف ويحدد: النوع، الشدة، الجهة، الألم، المحظورات، واقتراح المرحلة — وتراجعه وتصححه في خطوة سريعة.
3. **ولّد البرنامج** — تمارين المرحلة المناسبة من كل المناطق المختارة، عدّل الجرعات واحفظ واطبع.

### تحليل التقارير بالذكاء الاصطناعي (اختياري)

- **بدون أي إعداد**: المحلل المحلي يفهم الوصف المكتوب ونصوص ملفات PDF — يعمل أوفلاين ولا شيء يخرج من جهازك.
- **للصور والمستندات المسوّدة**: فعّل مفتاحًا مجانيًا من Google AI Studio مرة واحدة (الخطوات مكتوبة داخل الأداة في صفحة النسخ الاحتياطي).

## المميزات

- مكتبة **+٧٥ تمرين** تغطي ١٣ منطقة، من إعادة التأهيل الأساسي لحد التمارين الوظيفية المتقدمة (سبرنت، بلايومتركس، تغيير اتجاه، مهارات المركز) برسوم SVG توضيحية.
- إرشادات خاصة بنوع الإصابة (شد عضلي / التواء / وتر / إجهاد مزمن / بعد جراحة / عظمية) لكل مرحلة من المراحل الأربعة.
- **خط زمني متوقع للتعافي**: شريط مرئي بمدد كل مرحلة حسب نوع ودرجة الإصابة وعلامة «النهارده» إنت فين.
- **ترقية تلقائية بين المراحل**: لما آخر ٣ جلسات تكون مستقرة الألم فيها، الأداة تقترح الانتقال للمرحلة الجاية وتولّد برنامجها بضغطة. ولو الألم بيزيد تنبهك تقلل الأحمال.
- **اختبارات الرجوع للملاعب**: تشيك ليست معيارية لكل منطقة + اختبارات عامة، بنسبة جاهزية وتاريخ اجتياز كل اختبار.
- **شيت الجلسة اليومي**: ورقة طباعة واحدة لجلسة النهارده مع QR code — اللاعب يمسحه بموبايله فيفتح البرنامج وفيديوهات كل تمرين.
- **مشاركة برابط**: انسخ رابط البرنامج أو ابعتها واتساب — تفتح نسخة قراءة فقط من أي موبايل (البرنامج كله مشفر داخل الرابط، بدون سيرفر).
- **تقرير للطبيب**: PDF يلخص الإصابات وتطور الألم والبرامج واختبارات الجاهزية — للتواصل مع الفريق الطبي.
- **برامج وقاية جماعية**: ٥ بروتوكولات جاهزة للفريق كله (إحماء شامل، وقاية المأبضية/الركبة/الضامّة/الكاحل) بطباعة ومشاركة.
- فيديوهات: بحث يوتيوب تلقائي لكل تمرين + حفظ رابط مفضل + **رفع فيديو من جهازك** يعمل أوفلاين (IndexedDB).
- سجل لاعبين + متابعة ألم/RPE بعد كل جلسة مع منحنى تطور.
- **تذكير نسخة احتياطية**: الأداة تنبهك لو عدى أسبوع من غير تصدير.
- أضف تمارينك الخاصة، ونسخ احتياطي JSON ينتقل لأي جهاز.

## الملفات

| ملف | الوظيفة |
|---|---|
| index.html | الهيكل والصفحات |
| data.js | مكتبة التمارين والمراحل والمحلل والخطوط الزمنية والاختبارات وبرامج الوقاية |
| app.js | منطق التطبيق كاملًا |
| style.css | التنسيقات والطباعة |
| qrcode.min.js | توليد QR محلي (أوفلاين) |
| manifest.json + sw.js + icon-*.png | ملفات التطبيق (PWA) |
| serve.js | سيرفر تجربة محلي فقط — مش للرفع |

## الرفع كـ ويب سايت (اختياري)

المجلد ملفات ثابتة — ارفعه كما هو على أي استضافة ثابتة. الـ service worker هيخلي الأداة تعمل أوفلاين بعد أول زيارة. عند أي تحديث للموقع: غيّر رقم `CACHE` في `sw.js` (مثال `returnplay-v2` ← `returnplay-v3`).

## حدود الأداة

هذه أداة مساعدة لتوليد مسودات برامج واختبارات إرشادية فقط. القرار بالتمارين والجرعات والعودة للملاعب يبقى للطبيب وأخصائي العلاج الطبيعي/التأهيل. الفيديوهات تُفتح من يوتيوب (تحتاج إنترنت) — باقي الأداة تعمل أوفلاين بالكامل.
